# Contributing

Issues and pull requests are welcome for reproducible bug fixes, data-quality improvements and source-agnostic dashboard features.

1. Create a focused branch.
2. Use synthetic data in tests and examples.
3. Run `npm test` and `npm run lint`.
4. Explain the user-visible effect and any schema implications.

Do not submit live credentials, browser sessions, raw marketplace exports, private notes or personal contact information. Source integrations must respect the source's terms and access controls.
